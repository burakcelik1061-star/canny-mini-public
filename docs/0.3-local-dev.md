`docker-compose.yml` (Postgres 16 + Redis 7) ve `.env.example` oluşturuldu,
`.env` yerelde kopyalandı (gitignored). Ama bu makinede Docker kurulu olmadığı

kurulum (WSL2/Hyper-V gerektirebilir) olduğu için bunu senin yapman gerekiyor.

## Kurulum adımları

1. **Docker Desktop'ı indir ve kur:** https://www.docker.com/products/docker-desktop/
   - Windows'ta kurulum sırasında "WSL 2" tabanlı backend'i seçmesi önerilir
     (installer genelde otomatik önerir, evet de).
   - Kurulum bitince bilgisayarı yeniden başlatman istenebilir.
2. Docker Desktop'ı aç, sol alttaki motorun **yeşil/çalışıyor** olduğunu gör.
3. Aşağıdaki komutu proje kök dizininde çalıştır:

```bash
cd C:\Users\burak\Projects\canny-mini
docker compose up -d
```

4. Kontrol et:

```bash
docker compose ps
```

İkisi de `healthy`/`running` görünmeli (`canny-mini-postgres`, `canny-mini-redis`).

5. İstersen bağlantıyı test et:

```bash
docker exec -it canny-mini-postgres psql -U canny -d canny_mini -c "SELECT 1;"
docker exec -it canny-mini-redis redis-cli ping
```

`psql` `1` satırı, `redis-cli` `PONG` dönerse ortam çalışıyor demektir.

6. Durdurmak istediğinde: `docker compose down` (veriyi de silmek istersen `-v` ekle).
